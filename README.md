# StyleMuse AI

Cross-platform smart wardrobe application. Android-first Flutter development.

## First milestone
- Wardrobe overview
- Add clothing items
- Outfit ideas
- Local-first storage (planned)

## Setup
1. Install Flutter SDK and Android Studio with Flutter/Dart plugins.
2. Run `flutter create --platforms=android,ios .` in the cloned repository.
3. Run `flutter run` on an Android emulator or phone.

The initial UI is a prototype. Persistent storage, photos, AI and subscriptions are not implemented yet.
